🇬🇧 English — GUI Command Guide

⬆ Top

🚀 Overview: Local, resilient Web Interface for the bash4llm wrapper script.

💬 Sidebar & Threads

  • + New Thread: Create a new session thread.
  • Thread List: Switch between active conversation histories.
  • 🗑️ Delete: Permanently delete current conversation thread or clear default chat history.
  • 📊 Stats: View Session Engine snapshot metrics (Total message count, segment allocations, total byte size).
  • 🔒 Vault: Open OpenSSL master key manager dialog.
  • ⚙️ Settings: Open runtime parameter configuration modal.
  • 🛑 Stop (Server): Cleanly shut down and terminate the local WebApp backend server instance.

✍️ Input Controls & Message Feed

  • Prompt: Enter user query or instruction.
  • 📎 Attach: Upload context file (mapped to -f flag).
  • Templates: Apply structured prompt template from repository.
  • Stream: Toggle real-time token streaming on or off (blocking full-response mode).
  • SML Gate: Structured Metadata Layout validator. Forces validation of the AI output schema (requires mandatory LISTEN_SUMMARY and CONVERSATION_OUTCOME blocks). If the model hallucinates or fails the schema, SML Gate blocks execution and flags output as unverified.
  • ⧉ Copy: Copy the entire text of a single message to clipboard with instant visual confirmation (✓).
  • Send / Stop: Submit query stream or interrupt active SSE job immediately.

⚙️ Runtime Settings

  • Provider / Model: Select active LLM provider engine and inference model.
  • Set Default: Persist preferred model for active provider.
  • 🔄 Refresh: Query provider endpoint for live updated model catalogs.
  • Params: Set System Prompt, Temperature (0.0 - 2.0), and Token Limits.
  • Context Strategy: Switch between Message Count Window (N Messages) or Token/Byte Budget Mode (Target Bytes: 8 KB to 128 KB).
  • Output Sanitization: Strip terminal ANSI escape sequences and non-printable binary streams.

🔒 OpenSSL Key Vault

The Vault securely manages API keys locally using OpenSSL AES-256 encryption on the host filesystem.

  • Initialization: Create Master Password (minimum 11 characters) on clean install. Generates an emergency offline Recovery Key.
  • Unlock Vault Session: Authenticate session in memory via Master Password (_B4L_RT_CTX).
  • Save Encrypted Key: Store encrypted API credentials for builtin, vendor, or custom providers (Custom Provider Name).

🇮🇹 Italiano — Guida ai comandi della GUI

⬆ Torna su

🚀 Panoramica: Interfaccia web locale ad alta resilienza per lo script wrapper bash4llm.

💬 Barra laterale e thread

  • + Nuova Chat: Crea un nuovo thread di sessione.
  • Elenco thread: Seleziona un thread per cambiare cronologia conversazione.
  • 🗑️ Elimina: Elimina definitivamente la chat corrente o cancella la cronologia della chat predefinita.
  • 📊 Statistiche: Visualizza le metriche del Session Engine (Conteggio messaggi, segmenti allocati, utilizzo totale byte).
  • 🔒 Vault: Apri la finestra modale del gestore chiavi crittografate.
  • ⚙️ Impostazioni: Configura i parametri di esecuzione a runtime.
  • 🛑 Arresta (Server): Arresta in modo sicuro e chiudi l'istanza del server backend locale.

✍️ Controlli di input e messaggi

  • Prompt: Inserisci la query o l'istruzione per il modello.
  • 📎 Allega: Carica un file di contesto (flag -f).
  • Template: Applica un template di prompt predefinito.
  • Stream: Attiva o disattiva la generazione in tempo reale (passando alla modalità risposta intera).
  • SML Gate: (Structured Metadata Layout) Verifica che la risposta dell'IA rispetti lo schema obbligatorio (blocchi LISTEN_SUMMARY e CONVERSATION_OUTCOME). In caso di allucinazione o schema incompleto, SML Gate blocca l'output non conforme.
  • ⧉ Copia: Copia l'intero testo del singolo messaggio negli appunti con conferma visiva immediata (✓).
  • Invia / Interrompi: Avvia lo streaming o cancella immediatamente il job SSE in corso.

⚙️ Impostazioni di runtime

  • Provider / Modello: Seleziona il backend LLM e il modello attivo.
  • Imposta predefinito: Memorizza il modello di default per il provider selezionato.
  • 🔄 Aggiorna: Interroga l'API remota per scaricare l'elenco modelli aggiornato.
  • Parametri: Regola Prompt di sistema, Temperatura (0.0 - 2.0) e Token massimi.
  • Strategia contesto: Alterna tra conteggio messaggi (N) o budget token/byte target (8 KB - 128 KB).
  • Sanificazione output: Rimuove sequenze ANSI e residui binari dal log.

🔒 Vault chiavi OpenSSL

Il modulo Vault cifra le chiavi API direttamente sul filesystem locale tramite cifratura AES-256.

  • Inizializzazione: Creazione Master Password (minimo 11 caratteri) su installazione pulita con generazione chiave di recupero offline.
  • Sblocca sessione Vault: Autentica la sessione attiva in memoria tramite Master Password (_B4L_RT_CTX).
  • Salva chiave crittografata: Memorizza credenziali cifrate per provider ufficiali o personalizzati (Nome provider personalizzato).

🇪🇸 Español — Guía de comandos de la GUI

⬆ Arriba

🚀 Resumen: Interfaz web local de alta resiliencia para el script wrapper bash4llm.

💬 Barra lateral e hilos

  • + Nuevo chat: Crea un nuevo hilo de sesión.
  • Lista de hilos: Cambia entre historiales de conversación activos.
  • 🗑️ Eliminar: Elimina permanentemente el chat actual o limpia el historial predeterminado.
  • 📊 Estadísticas: Visualiza métricas de la sesión (recuento de mensajes, segmentos asignados, uso total de bytes).
  • 🔒 Vault: Abre el gestor de claves OpenSSL.
  • ⚙️ Configuración: Abre los parámetros de ejecución.
  • 🛑 Detener (Servidor): Apaga y finaliza de forma segura el servidor local de la WebApp.

✍️ Controles de entrada y mensajes

  • Prompt: Introduce la consulta o instrucción.
  • 📎 Adjuntar: Sube un archivo de contexto (opción -f).
  • Plantillas: Aplica una plantilla de prompt.
  • Stream: Alterna la transmisión en tiempo real de tokens.
  • SML Gate: Valida el esquema Structured Metadata Layout (bloques LISTEN_SUMMARY y CONVERSATION_OUTCOME).
  • ⧉ Copiar: Copia el texto completo de un mensaje individual al portapapeles con confirmación visual (✓).
  • Enviar / Detener: Envía la petición o cancela la transmisión SSE activa.

⚙️ Configuración de ejecución

  • Proveedor / Modelo: Configura el proveedor y modelo activo.
  • Establecer predeterminado: Guarda el modelo por defecto.
  • 🔄 Actualizar: Actualiza la lista de modelos remotos.
  • Parámetros: Ajusta Prompt del sistema, Temperatura (0.0 - 2.0) y Tokens máximos.
  • Estrategia de contexto: Alterna entre recuento de mensajes (N) o presupuesto de tokens/bytes (8 KB - 128 KB).
  • Sanitización: Elimina códigos ANSI y residuos binarios.

🔒 Vault OpenSSL

Almacenamiento seguro cifrado localmente mediante AES-256.

  • Inicialización: Crear contraseña maestra (mínimo 11 caracteres) en instalación limpia con clave de recuperación offline.
  • Desbloquear sesión: Autentica la sesión activa en memoria (_B4L_RT_CTX).
  • Guardar clave cifrada: Guarda claves API para proveedores estándar o personalizados (Nombre de proveedor personalizado).

🇩🇪 Deutsch — GUI-Befehlsanleitung

⬆ Nach oben

🚀 Übersicht: Lokale, hochverfügbare Web-Benutzeroberfläche für das bash4llm-Wrapper-Skript.

💬 Seitenleiste & Threads

  • + Neuer Chat: Neuen Chat-Thread initialisieren.
  • Thread-Liste: Zwischen Unterhaltungen wechseln.
  • 🗑️ Löschen: Den aktuellen Thread dauerhaft löschen oder den Standard-Chat leeren.
  • 📊 Statistiken: Sitzungsmetriken abrufen (Nachrichtenanzahl, Segmente, Byte-Größe).
  • 🔒 Vault: OpenSSL-Schlüssel-Vault öffnen.
  • ⚙️ Einstellungen: Laufzeitkonfiguration anpassen.
  • 🛑 Stoppen (Server): Den lokalen WebApp-Serverprozess sicher herunterfahren.

✍️ Eingabesteuerung und Nachrichten

  • Prompt: Benutzeranfrage eingeben.
  • 📎 Anhängen: Kontextdatei anhängen (Flag -f).
  • Templates: Prompt-Vorlage anwenden.
  • Stream: Echtzeit-Token-Streaming aktivieren oder deaktivieren.
  • SML Gate: Erzwingt Structured Metadata Layout Schemaprüfung (LISTEN_SUMMARY und CONVERSATION_OUTCOME).
  • ⧉ Kopieren: Kopiert den gesamten Text einer einzelnen Nachricht mit visueller Bestätigung (✓) in die Zwischenablage.
  • Senden / Stopp: Stream ausführen oder sofort abbrechen.

⚙️ Laufzeit-Einstellungen

  • Anbieter / Modell: Backend und aktives Modell auswählen.
  • Als Standard festlegen: Standardmodell für den Anbieter speichern.
  • 🔄 Aktualisieren: Modellkatalog vom Anbieter aktualisieren.
  • Parameter: System-Prompt, Temperatur (0.0 - 2.0) und Max. Tokens anpassen.
  • Kontextstrategie: Wechsel zwischen Nachrichtenanzahl (N) oder Token/Byte-Budget-Modus (8 KB - 128 KB).
  • Ausgabebereinigung: Entfernt ANSI-Codes und Binärzeichen.

🔒 OpenSSL-Schlüssel-Vault

Lokale, sichere AES-256-Verschlüsselung auf dem Dateisystem.

  • Initialisierung: Master-Passwort erstellen (mindestens 11 Zeichen) mit Offline-Wiederherstellungsschlüssel.
  • Vault entsperren: Aktive Sitzung im Arbeitsspeicher authentifizieren (_B4L_RT_CTX).
  • Schlüssel speichern: API-Schlüssel für Standard- oder benutzerdefinierte Anbieter sichern (Benutzerdefinierter Anbietername).
