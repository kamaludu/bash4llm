🇬🇧 GUI Command Guide

🚀 Overview: Local Web Interface for the bash4llm wrapper script.

💬 Sidebar & Threads
  • + New Thread
    Create a new session thread.
  • Thread List
    Select thread to switch conversation.
  • 📊 Stats
    View session message count and byte usage.
  • 🔒 Vault
    Open key manager modal.
  • Settings
    Open runtime configuration modal.
✍️ Input Controls
  • Prompt
    Enter user query or instruction.
  • 📎 Attach
    Upload context file (-f flag).
  • Templates
    Apply prompt template from list.
  • SML Gate
    (Structured Metadata Layout) Validates that the AI response contains mandatory summary and outcome sections.
  • Send / Stop
    Submit query or interrupt streaming.
⚙️ Runtime Settings
  • Provider / Model
    Select active LLM backend and model.
  • Set Default
    Save default model for active provider.
  • 🔄
    Fetch updated model list from provider.
  • Params
    Set System Prompt, Temperature, Max Tokens.
  • Context Window Strategy
    Select Message Count Window (N Messages) or Token/Byte Budget Mode (Target Bytes).
  • Enable Output Sanitization
    Strip ANSI codes and binaries.
🔒 OpenSSL Key Vault
  • Unlock Vault Session
    Authenticate session with Master Password.
  • Save Encrypted Key
    Store encrypted API keys (AES-256).

🇫🇷 Guide des commandes de la GUI

🚀 Aperçu: Interface web locale pour le script wrapper bash4llm.

💬 Barre latérale et threads
  • + Nouveau thread
    Créer un nouveau thread de session.
  • Liste des threads
    Sélectionner un thread pour changer de conversation.
  • 📊 Statistiques
    Afficher le nombre de messages et l'utilisation des octets de la session.
  • 🔒 Vault
    Ouvrir la fenêtre modale du gestionnaire de clés.
  • Paramètres
    Ouvrir la fenêtre modale de configuration d'exécution.
✍️ Contrôles de saisie
  • Prompt
    Saisir la requête ou l'instruction de l'utilisateur.
  • 📎 Joindre
    Téléverser un fichier de contexte (option -f).
  • Templates
    Appliquer un template de prompt depuis la liste.
  • SML Gate
    (Structured Metadata Layout) Valide que la réponse de l'IA contient les sections obligatoires de résumé et de résultat.
  • Envoyer / Arrêter
    Soumettre la requête ou interrompre le flux.
⚙️ Paramètres d'exécution
  • Fournisseur / Modèle
    Sélectionner le backend LLM et le modèle actifs.
  • Définir par défaut
    Enregistrer le modèle par défaut pour le fournisseur actif.

    Récupérer la liste à jour des modèles depuis le fournisseur.

    Définir le prompt système, la température et les tokens max.
  • Stratégie de fenêtre de contexte
    Sélectionner Fenêtre de nombre de messages (N messages) ou Mode budget tokens/octets (Octets cibles).

    Supprimer les codes ANSI et les binaires.

  • Déverrouiller la session du Vault
    Authentifier la session avec le mot de passe maître.
  • Enregistrer la clé chiffrée
    Stocker les clés API chiffrées (AES-256).

🇩🇪 GUI-Befehlsanleitung

🚀 Übersicht: Lokale Web-Benutzeroberfläche für das bash4llm-Wrapper-Skript.

💬 Seitenleiste & Threads
  • + Neuer Thread
    Einen neuen Sitzungs-Thread erstellen.
  • Thread-Liste
    Thread auswählen, um die Unterhaltung zu wechseln.
  • 📊 Statistiken
    Sitzungsnachrichtenanzahl und Byte-Nutzung anzeigen.
  • 🔒 Vault
    Schlüsselmanager-Modal öffnen.
  • Einstellungen
    Laufzeit-Konfigurationsmodal öffnen.
✍️ Eingabesteuerung
  • Prompt
    Benutzeranfrage oder -anweisung eingeben.
  • 📎 Anhängen
    Kontextdatei hochladen (Flag -f).
  • Templates
    Prompt-Template aus der Liste anwenden.
  • SML Gate
    (Structured Metadata Layout) Überprüft, ob die KI-Antwort die obligatorischen Abschnitte Zusammenfassung und Ergebnis enthält.
  • Senden / Stopp
    Anfrage übermitteln oder Streaming unterbrechen.
⚙️ Laufzeit-Einstellungen
  • Anbieter / Modell
    Aktives LLM-Backend und Modell auswählen.
  • Als Standard festlegen
    Standardmodell für aktiven Anbieter speichern.
  • 🔄
    Aktualisierte Modellliste vom Anbieter abrufen.
  • Parameter
    System-Prompt, Temperatur und max. Tokens festlegen.
  • Kontextfenster-Strategie
    Nachrichtenanzahl-Fenster (N Nachrichten) oder Token/Byte-Budget-Modus (Ziel-Bytes) auswählen.
  • Ausgabebereinigung aktivieren
    ANSI-Codes und Binärdateien entfernen.
🔒 OpenSSL-Schlüssel-Vault
  • Vault-Sitzung entsperren
    Sitzung mit Master-Passwort authentifizieren.
  • Verschlüsselten Schlüssel speichern
    Verschlüsselte API-Schlüssel speichern (AES-256).
