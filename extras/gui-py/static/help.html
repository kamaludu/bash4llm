🚀 Overview

Local Web Interface for the bash4llm wrapper script.

💬 Sidebar & Threads

  • + New Thread: Create a new session thread.
  • Thread List: Select thread to switch conversation.
  • 📊 Stats: View session message count and byte usage.
  • 🔒 Vault: Open key manager modal.
  • Settings: Open runtime configuration modal.

✍️ Input Controls

  • Prompt: Enter user query or instruction.
  • 📎 Attach: Upload context file (-f flag).
  • Templates: Apply prompt template from list.
  • SML Gate: Enable SML v2.0 output validation.
  • Send / Stop: Submit query or interrupt streaming.

⚙️ Runtime Settings

  • Provider / Model: Select active LLM backend and model.
  • Set Default: Save default model for active provider.
  • 🔄 Refresh: Fetch updated model list from API.
  • Params: Set System Prompt, Temperature, Max Tokens.
  • Context Mode: Select N Messages window or Byte Budget.
  • Sanitize: Strip ANSI codes and non-printable bytes.

🔒 OpenSSL Key Vault

  • Unlock: Authenticate session with Master Password.
  • Save Key: Store encrypted API keys (AES-256).
