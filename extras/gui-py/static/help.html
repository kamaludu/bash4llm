🇬🇧 GUI Command Guide
🚀 Overview

Local Web Interface for the bash4llm wrapper script.

💬 Sidebar & Threads
  • + New Thread: Create a new session thread.
  • Thread List: Select thread to switch conversation.
  • 📊 Stats: View session message count and byte usage.
  • 🔒 Vault: Open key manager modal.
  • Settings: Open runtime configuration modal.
✍️ Input Controls
  • Prompt: Enter user query or instruction.
  • 📎 Attach: Upload context file (-f flag).
  • Templates: Apply prompt template from list.
  • SML Gate: (Structured Metadata Layout) Validates that the AI response contains the mandatory summary and outcome sections.
  • Send / Stop: Submit query or interrupt streaming.
⚙️ Runtime Settings
  • Provider / Model: Select active LLM backend and model.
  • Set Default: Save default model for active provider.
  • 🔄 Refresh: Fetch updated model list from API.
  • Params: Set System Prompt, Temperature, Max Tokens.
  • Context Mode: Select N Messages window or Byte Budget.
  • Sanitize: Strip ANSI codes and non-printable bytes.
🔒 OpenSSL Key Vault
  • Unlock: Authenticate session with Master Password.
  • Save Key: Store encrypted API keys (AES-256).

Interfaccia web locale per lo script wrapper bash4llm.

💬 Barra laterale e chat
  • + Nuova chat: Crea una nuova chat di sessione.
  • Elenco chat: Seleziona una chat per cambiare conversazione.

  • 📎 Allega: Carica un file di contesto (flag -f).
  • Template: Applica un template di prompt dall'elenco.
  • SML Gate: (Structured Metadata Layout) Verifica che la risposta dell'IA contenga le sezioni obbligatorie di sommario e risultato.
  • Invia / Interrompi: Invia la query o interrompi lo streaming.
⚙️ Impostazioni di runtime
  • Provider / Modello: Seleziona il backend LLM e il modello attivi.
  • Imposta predefinito: Salva il modello predefinito per il provider attivo.

🔒 Vault chiavi OpenSSL
  • Sblocca: Autentica la sessione con la master password.
  • Salva chiave: Salva le chiavi API crittografate (AES-256).

🚀 Resumen

Interfaz web local para el script wrapper bash4llm.

💬 Barra lateral y chats
  • + Nuevo chat: Crea un nuevo chat de sesión.
  • Lista de chats: Selecciona un chat para cambiar de conversación.
  • 📊 Estadísticas: Muestra el recuento de mensajes de la sesión y el uso de bytes.
  • 🔒 Vault: Abre la ventana modal del gestor de claves.
  • Configuración: Abre la ventana modal de configuración de ejecución.
✍️ Controles de entrada
  • Prompt: Introduce la consulta o instrucción del usuario.
  • 📎 Adjuntar: Carga un archivo de contexto (opción -f).
  • Plantillas: Aplica una plantilla de prompt de la lista.
  • SML Gate: (Structured Metadata Layout) Valida que la respuesta de la IA contenga las secciones obligatorias de resumen y resultado.
  • Enviar / Detener: Envía la consulta o interrumpe la transmisión.
⚙️ Configuración de ejecución
  • Proveedor / Modelo: Selecciona el backend de LLM y el modelo activos.
  • Establecer como predeterminado: Guarda el modelo predeterminado para el proveedor activo.
  • 🔄 Actualizar: Obtiene la lista actualizada de modelos desde la API.
  • Parámetros: Define el prompt del sistema, la temperatura y los tokens máximos.
  • Modo de contexto: Selecciona la ventana de recuento de N mensajes o el presupuesto de bytes.
  • Sanitizar: Elimina códigos ANSI y bytes no imprimibles.
🔒 Vault de claves OpenSSL
  • Desbloquear: Authentica la sesión con la contraseña maestra.
  • Guardar clave: Almacena claves API cifradas (AES-256).
🇫🇷 Guide des commandes de la GUI
🚀 Aperçu

Interface web locale pour le script wrapper bash4llm.

💬 Barre latérale et chats
  • + Nouveau chat : Créer un nouveau chat de session.
  • Liste des chats : Sélectionner un chat pour changer de conversation.
  • 📊 Statistiques : Afficher le nombre de messages et l'utilisation des octets de la session.
  • 🔒 Vault : Ouvrir la fenêtre modale du gestionnaire de clés.
  • Paramètres : Ouvrir la fenêtre modale de configuration d'exécution.
✍️ Contrôles de saisie
  • Prompt : Saisir la requête ou l'instruction de l'utilisateur.
  • 📎 Joindre : Téléverser un fichier de contexte (option -f).
  • Templates : Appliquer un template de prompt depuis la liste.
  • SML Gate : (Structured Metadata Layout) Valide que la réponse de l'IA contient les sections obligatoires de résumé et de résultat.
  • Envoyer / Arrêter : Soumettre la requête ou interrompre le flux.
⚙️ Paramètres d'exécution
  • Fournisseur / Modèle : Sélectionner le backend LLM et le modèle actifs.
  • Définir par défaut : Enregistrer le modèle par défaut pour le fournisseur actif.
  • 🔄 Actualiser : Récupérer la liste à jour des modèles depuis l'API.
  • Paramètres : Définir le prompt système, la température et les tokens max.
  • Mode de contexte : Sélectionner la fenêtre de N messages ou le budget d'octets.
  • Assainir : Supprimer les codes ANSI et les octets non imprimables.
🔒 Vault de clés OpenSSL
  • Déverrouiller : Authentifier la session avec le mot de passe maître.
  • Enregistrer la clé : Stocker les clés API chiffrées (AES-256).
🇩🇪 GUI-Befehlsanleitung
🚀 Übersicht

Lokale Web-Benutzeroberfläche für das bash4llm-Wrapper-Skript.

💬 Seitenleiste & Chats
  • + Neuer Chat: Einen neuen Sitzungs-Chat erstellen.
  • Chat-Liste: Chat auswählen, um die Unterhaltung zu wechseln.
  • 📊 Statistiken: Sitzungsnachrichtenanzahl und Byte-Nutzung anzeigen.
  • 🔒 Vault: Schlüsselmanager-Modal öffnen.
  • Einstellungen: Laufzeit-Konfigurationsmodal öffnen.
✍️ Eingabesteuerung
  • Prompt: Benutzeranfrage oder -anweisung eingeben.
  • 📎 Anhängen: Kontextdatei hochladen (Flag -f).
  • Templates: Prompt-Template aus der Liste anwenden.
  • SML Gate: (Structured Metadata Layout) Überprüft, ob die KI-Antwort die obligatorischen Abschnitte Zusammenfassung und Ergebnis enthält.
  • Senden / Stopp: Anfrage übermitteln oder Streaming unterbrechen.
⚙️ Laufzeit-Einstellungen
  • Anbieter / Modell: Aktives LLM-Backend und Modell auswählen.
  • Als Standard festlegen: Standardmodell für aktiven Anbieter speichern.
  • 🔄 Aktualisieren: Aktualisierte Modellliste vom Anbieter abrufen.
  • Parameter: System-Prompt, Temperatur und max. Tokens festlegen.
  • Kontextmodus: Fenster für N Nachrichten oder Byte-Budget auswählen.
  • Bereinigen: ANSI-Codes und nicht druckbare Bytes entfernen.
🔒 OpenSSL-Schlüssel-Vault
  • Entsperren: Sitzung mit Master-Passwort authentifizieren.
  • Schlüssel speichern: Verschlüsselte API-Schlüssel speichern (AES-256).
