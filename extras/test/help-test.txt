========================================
Bash4LLM⁺ — Master Test Suite & Orchestrator CLI Manual
========================================

USAGE:
  bash4llm --test [COMMAND] [SUITE...] [OPTIONS]
  bash4llm --run-all-tests [COMMAND] [SUITE...] [OPTIONS]
  ./extras/test/run-all-tests.sh [COMMAND] [SUITE...] [OPTIONS]

COMMANDS:
  all                         Execute all canonical test suites in order (default)
  list                        List all authorized canonical test suites registered in manifest
  help, -h, --help            Display this test suite CLI help manual

CANONICAL TEST SUITES:
  sanity                      Level 1: System vitality & CLI flags check
  compatibility               Level 2: Public Compatibility Contract & Exit Codes (10..17)
  regression                  Level 3: End-to-end prompt assembly & thread lifecycle
  hardening                   Level 4: Security Invariants (INV-1..5) & boundary fuzzing
  concurrency                 Level 5: Multi-process lock contention & atomic NDJSON appends
  stress                      Level 6: High-volume payload staging & history rotation
  deterministic               Level 7: Deterministic SML v2.0, POSIX Regex & Output Sanitization

OPTIONS:
  --fail-fast                 Halt execution immediately upon the first assertion failure
  --no-color                  Disable ANSI terminal color output
  --dry-run                   Simulate test flows without executing external network calls

EXAMPLES:
  # Execute full test suite sequence (Level 1 through Level 7)
  bash4llm --test

  # Execute full test suite with fail-fast mode
  bash4llm --test all --fail-fast

  # Execute a single specific test level
  bash4llm --test sanity
  bash4llm --test hardening
  bash4llm --test deterministic

  # Execute multiple specific test levels sequentially
  bash4llm --test sanity compatibility regression deterministic

  # List all authorized canonical test suites
  bash4llm --test list

SECURITY & INTEGRITY:
  All test modules are verified against extras/manifest.sha256 before execution.
  Unregistered or modified test scripts are automatically rejected with Exit Code 17.
