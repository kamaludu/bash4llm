S:CORE_PROVIDER_PIPELINE_EXEC|p:Smistamento ed esecuzione pipeline|a:Smista ed esegue l'elaborazione nei tre rami principali:
1. BATCH ($BATCH_FILE): scansione riga per riga, recupero contestuale del thread (Session Engine o legacy), build_payload_from_vars, verifica API key ed esecuzione sequenziale.
2. CHAT ($CHAT_MODE): valorizza ed esporta BASH4LLM_CORE_SCRIPT, BASH4LLM_ACTIVE_THREAD, BASH4LLM_ACTIVE_MODEL, BASH4LLM_ACTIVE_TEMPERATURE, valida integrità crittografica di extras/chat/tui-repl.sh ed esegue exec bash "$tui_script" "$@".
3. SINGLE-SHOT: prepara finestra messaggi storici thread (Session Engine o legacy), compila payload, verifica chiave API ed esegue transazione HTTP (streaming SSE via call_api_streaming o sincrona via perform_request_once). Al rientro con successo, accoda in sicurezza richiesta utente e risposta assistente nel registro NDJSON del thread.
